# Contributing

Read [development](docs/development.md). Keep client interaction here and backend
business rules in [Keyholder](https://github.com/Ar-Atharifard/keyholder).
Do not import core/private source or copy account logic into the client.

Run the documented tests, Ruff checks and package build. Explain behavior changes,
compatible server versions and validation in the pull request. Use synthetic data;
never submit tokens, subscription links, receipts or private host configuration.

Contributions use [MIT](LICENSE). Preserve upstream notices. Disclose substantial
AI assistance and review the result to the same standard as other contributions.
