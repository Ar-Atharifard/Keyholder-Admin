# Security

Do not post credentials, subscription links or exploit details in public issues.
Use GitHub private vulnerability reporting when enabled; otherwise request a
private contact without including sensitive details.

Protect SSH identity/host verification, dispatcher authorization, Telegram tokens,
admin chats and local state. Client installation grants no server privileges.
Keep backend administration private; never distribute the administrator bot to
customers. Inspect state after uncertain mutations rather than blindly retrying.

Report client flaws here and server flaws to Keyholder, identifying both versions.
Historical versions have no guaranteed security-maintenance window.
